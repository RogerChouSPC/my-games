# my-games

A collection of personal web games.

## Games

- **[sequence-numbers/](sequence-numbers/)** — Real-time multiplayer Sequence Numbers (math
  edition). Teams race to line up chips on a board by solving math equations. Built with
  Next.js + Socket.io. See [sequence-numbers/DEPLOY.md](sequence-numbers/DEPLOY.md) for how it's
  hosted.

Each game is a self-contained folder with its own dependencies and deploy config.
