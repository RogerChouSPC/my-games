# How to run Number Wars on your PC (free)

This runs the game on your computer and gives you a temporary public link to share.
It works **only while your PC is on and the two windows are open.**

## To start a game night

1. Double-click **`start-game.bat`** (in this folder).
2. Two windows open:
   - **"Number Wars Server"** — the game engine. Leave it open.
   - The **launcher window** — watch it for a line like:
     ```
     https://random-words-here.trycloudflare.com
     ```
3. **That `https://...trycloudflare.com` link is what you share.** Send it to your friends.
4. One person clicks **Create Room**, shares the 4-letter code (or the link), everyone joins,
   assign teams, and play.

## To stop

Close both windows. The link stops working immediately.

## Notes

- The link is **different every time** you start (that's normal and actually good for privacy).
- The game only works while your PC is on with these windows running. For an always-on link,
  see `DEPLOY.md` (Railway, ~$5/month).
- Your computer is **not** exposed — only this one game is reachable through the link.
  See the security notes you discussed with Claude.

## Safety reminders

- Only share the link with people you want to play with.
- Closing the windows = the link is dead and nothing on your PC is reachable anymore.
