Put your "Super Sequence" GIFs in THIS folder.

When a team completes a full line (8 in a row on the 8x8 board, or 9 in a row on
the 9x9 board), the game pops up one of these GIFs at random in the centre of the screen.

- Drop image/GIF files here: .gif, .png, .jpg, .jpeg, .webp
- File names can be anything (e.g. fireworks.gif, boom.gif).
- If this folder is empty, the game shows a built-in "SUPER SEQUENCE!" banner instead.

After adding GIFs, restart the game (close and re-run start-game.bat) so they're picked up.
