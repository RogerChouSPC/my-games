Put your "Winner" celebration GIFs in THIS folder.

When a team wins a whole game, the board freezes and one of these GIFs is shown at
random in the centre, until the host presses "Next".

- Drop image/GIF files here: .gif, .png, .jpg, .jpeg, .webp
- File names can be anything (e.g. trophy.gif, celebrate.gif).
- If this folder is empty, the game shows a built-in trophy banner instead.

After adding GIFs, restart the game (close and re-run start-game.bat) so they're picked up.
